# Unisane Site Memory Router

This is the transitional documentation entrypoint for the future standalone
`unisane-site` repository. The umbrella remains the sole writable source authority, and
these documents do not authorize a rename, extraction, remote, publication, or deploy.

## Authority Boundary

The repository-readiness contract applies the accepted umbrella ecosystem, repository,
documentation, UI, security, and tooling authorities to the Site boundary. Those
umbrella owners remain authoritative until an explicit source-authority cutover. Site
product facts and unresolved decisions are kept visibly separate.
